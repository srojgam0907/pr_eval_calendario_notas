# 📅 CALENDARIO DE NOTAS

## ✍️ Descripción
Calendario de Notas es una aplicación web diseñada para ayudarte a organizar tus notas, recordatorios y tareas de manera mensual durante todo el año.

La idea es ofrecer una forma rápida y sencilla de registrar información importante para cada mes sin necesidad de instalar programas adicionales ni depender de aplicaciones complejas.

Con esta herramienta puedes:

1️⃣ Registrar notas y recordatorios importantes para cada mes del año.

2️⃣ Visualizar rápidamente tus notas organizadas por mes, evitando que se mezclen o se pierdan.

3️⃣ Tener un registro ordenado de tus actividades, compromisos o ideas.

## 🕹️ Instrucciones de uso

1. Abrir la página principal
- En esta vista encontrarás un listado con todos los meses del año 2026.
- Un botón **"Listar Notas"**, para listar todas las notas del año en la misma página.
- Un botón **"Limpiar Calendario"**, para limpiar todas las notas del año simultáneamente.

2. Seleccionar un mes
- Haz clic en el botón **"Ver notas"** del mes que quieras consultar o agregar información.

3. Crear una nueva nota
- Dirígete a la sección **"Nueva Nota"**.
- Escribe el contenido de tu nota en el campo de texto.
- Haz clic en **"Guardar Nota"** para que quede registrada en ese mes.

4. Ver notas existentes
- Todas las notas creadas para ese mes se mostrarán en la sección **"Notas guardadas"**.

5. Volver al calendario
- Para regresar a la vista general de meses, haz clic en **⬅ Calendario**.
